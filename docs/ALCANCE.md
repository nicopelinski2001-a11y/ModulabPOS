# Alcance comercial de esta entrega

La referencia vigente es el [README](../README.md), con su checklist y decisiones. El pedido histórico conservado en `PEDIDO-ORIGINAL.md` pertenece a un alcance anterior más amplio; no implica que este POS incluya una plataforma SaaS.

| Área              | Comportamiento entregado                                                                                                                                                      | Límite explícito                                                                                                                                             |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Venta             | Escaneo/búsqueda, unidades/peso, carrito persistente y suspendidas, descuento global, impuestos incluidos, todos los medios manuales/mixtos, vuelto, tickets/PDF, devolución  | Descuento autorizado por owner/admin; devolución total con reposición; sin promociones ni precios negociados por línea                                       |
| Integridad        | Transacciones, bloqueos, idempotencia, verificación diferida de stock/pagos/efectivo/impuestos/vuelto, libros inmutables                                                      | Una base compartida por comercio; infraestructura y administradores del host confiables                                                                      |
| Productos y stock | Alta, edición, desactivación, categoría, marca, proveedor, código, precios/costos, mínimo y alertas, movimientos/ajustes, importación/exportación CSV                         | Un código por producto y un depósito por comercio; sin lotes, vencimientos estructurados ni múltiples depósitos                                              |
| Caja              | Turnos únicos por caja/empleado, apertura, movimientos, cobros/reintegros, esperado vs contado, cierre definitivo, arqueo CSV/PDF                                             | Sin reapertura; todos los egresos requieren fondos suficientes; cierre administrativo por API autorizado                                                     |
| Usuarios          | Login, cuatro roles, CSRF, RLS, expiración e inactividad, cambio de contraseña, recuperación CLI auditada                                                                     | Sin correo externo, MFA ni permisos individuales configurables                                                                                               |
| Reportes          | Período local, ventas, descuentos, devoluciones, impuestos, costos históricos, resultado estimado, ocho más vendidos, pagos/pendientes, stock, CSV/PDF                        | Sin contabilidad fiscal. El resultado conserva impuestos incluidos en ventas/costos ingresados. Hasta 367 días por consulta                                  |
| Pagos             | Registro manual, pendiente explícito, confirmación posterior con referencia inmutable, reintegro comercial                                                                    | La aplicación no cobra tarjetas, certifica acreditación bancaria ni ejecuta reintegros electrónicos                                                          |
| Tickets           | Vista/reimpresión 58/80 mm, snapshot del comercio/tasas, pagos/vuelto y PDF                                                                                                   | Comerciales no fiscales; hardware y drivers de destino requieren prueba; sin impresión silenciosa/ESC/POS directo                                            |
| Compras/clientes  | Se preservan pedidos, recepción completa, costos, proveedores, cuenta corriente, límites y cobranzas                                                                          | Módulos existentes, sin ampliar a contabilidad, recepción parcial o gestión crediticia avanzada                                                              |
| Resiliencia       | Sin dependencia de internet, servidor local, consulta aun si navegador indica offline, indicador de conexión, recuperación de respuesta perdida y coordinación entre pestañas | Sin confirmación durante pérdida de servidor/LAN y sin sincronización de bases independientes                                                                |
| Operación         | Instalador Linux, secretos aleatorios, servicios/timer, backup/checksum/restauración, paquete, despliegue Docker y CI                                                         | Imágenes verificadas con Podman; Compose/HTTPS y hardware Windows/impresora necesitan validarse allí; no se afirma certificación ni compatibilidad universal |

Los adaptadores manual/comercial son funcionales sin servicios externos. Para cobro automático o factura fiscal se debe implementar un proveedor autorizado detrás de los contratos existentes y configurar credenciales reales; no hay una variable que simule una autorización.
